👗 Fashion Store Management System

Java Swing Desktop Application with SQLite Database

💻 GUI Usage Guide

Login Form

  1. Enter username: admin
  2. Enter password: password123
  3. Click "Login" button
  4. On success, Dashboard opens

Dashboard - Add Products

  1. Fill in product details (left panel):
    • Product Name: e.g., "Blue T-Shirt"
    • Category: e.g., "Shirts"
    • Price: e.g., "29.99"
    • Quantity: e.g., "50"
  2. Click "Add Product" button
  3. Product appears in the table on the right

Dashboard - View Products

  • Click "Refresh" to load all products
  • Table displays: ID, Name, Category, Price, Quantity

Dashboard - Search Products

  1. Type search term in search field (e.g., "shirt", "dresses")
  2. Click "Search" button
  3. Table updates with matching products

Dashboard - Update Products

  1. Click a row in the product table to select it
  2. Product details auto-populate in the input fields
  3. Modify the details as needed
  4. Click "Update Selected" button
  5. Table refreshes with updated data

Dashboard - Delete Products

  1. Click a row in the product table to select it
  2. Click "Delete Selected" button
  3. Confirm deletion in the dialog
  4. Product is removed from database

🏗️ Architecture & Design Patterns

Singleton Pattern

DatabaseManager uses the Singleton design pattern to ensure only one database connection instance exists throughout the application lifecycle.

public static synchronized DatabaseManager getInstance() {
    if (instance == null) {
        instance = new DatabaseManager();
    }
    return instance;
}

MVC-like Structure

  • Model: Product.java - Data representation
  • View: LoginForm.java, DashboardForm.java - GUI components
  • Controller: DatabaseManager.java - Business logic & data access

Key Operations

  • CREATE: addProduct()
  • READ: getAllProducts(), searchProducts()
  • UPDATE: updateProduct()
  • DELETE: deleteProduct()

🔧 Troubleshooting

Issue: "SQLite JDBC driver not found"

Solution: Use the pre-built JAR which includes all dependencies. Or run with Maven: mvn exec:java

Issue: "No X11 DISPLAY variable was set"

Solution: This happens in headless environments. Run the app on a machine with a display or use a virtual display.

Issue: Database file growing too large

Solution: Delete fashion_store.db to reset the database. A new one will be created on next run.

Issue: Port 8000 already in use

Solution: This project doesn't use ports. If you see this, you may have another application running.
